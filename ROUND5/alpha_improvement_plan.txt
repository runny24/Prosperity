3. Priority implementation plan

Step 1: Add a microstructure overlay to the existing baseline.

Goal:
- Improve entries/exits and reduce bad fills without changing the whole strategy.

Implementation:
- For every product with an order book, compute:
  - best_bid, best_ask, mid
  - spread
  - imbalance_1 = (bid_volume_1 - ask_volume_1) / (bid_volume_1 + ask_volume_1)
  - imbalance_3 = (sum_bid_vol_1_3 - sum_ask_vol_1_3) / total_depth_1_3
  - microprice = (ask * bid_volume_1 + bid * ask_volume_1) / (bid_volume_1 + ask_volume_1)
  - micro_edge = microprice - mid

Use a combined short-horizon score:
- micro_score = +w1 * imbalance_1 + w2 * micro_edge_ticks - w3 * imbalance_3

Initial simple weights:
- w1 = 1.0
- w2 = 0.5
- w3 = 1.0

Use it conservatively:
- If EMA target is long, only buy aggressively when micro_score is positive.
- If EMA target is short, only sell aggressively when micro_score is negative.
- If micro_score disagrees with EMA, either quote passively only or reduce target by half.
- If flat and abs(micro_score) is very high, allow small position, e.g. +/-2, especially in SNACKPACK.

Why this should help:
- The baseline currently crosses spreads based on slow EMA state.
- The strongest notebook alpha is a 1-5 tick book signal, which is exactly the horizon that decides whether a taker fill is good or bad.

Step 2: Add microstructure products that baseline does not trade.

Start with SNACKPACK products because they had very clean product-level imbalance IC:
- SNACKPACK_PISTACHIO
- SNACKPACK_CHOCOLATE
- SNACKPACK_VANILLA

Initial rule:

- Position limit target should be smaller than the baseline trend products at first, e.g. +/-4 or +/-5.
- Use taker orders only when expected edge exceeds spread cost.
- Otherwise place passive orders one tick inside the book in the predicted direction.

Acceptance test:
- Backtest day 2, day 3, day 4 separately.
- Keep a product only if all-day aggregate is positive or if losses are small and signal IC remains stable.

Weak in current online-style log:

Rationale:

  but slow EMA is vulnerable to full-day trend overfit.

Step 4: Expand family-relative mean reversion.

Current baseline only has an explicit structural fair-value rule for PEBBLES_XL:
- PEBBLES_XL fair = 50000 - sum(other PEBBLES mids)

Keep that rule, but add a general family z-score module:
- For each family, keep rolling log-mid history per product.
- Compute family mean log price at each timestamp.
- Compute product residual = log_mid - family_mean.
- Track rolling mean/std of residual.
- z = (residual - rolling_mean) / rolling_std.

Initial trade rule:
- If z > +1.5, product is rich: bias short.
- If z < -1.5, product is cheap: bias long.
- Exit when abs(z) < 0.5.
- Use horizon 20-100; do not churn every tick.

Prioritize these:
- PEBBLES family
- SNACKPACK family
- PANEL family
- MICROCHIP family

Start with pair-specific versions before a full family basket:
- PEBBLES_XL vs PEBBLES_XS
- PANEL_2X2 vs PANEL_4X4
- PEBBLES_M vs PEBBLES_S
- SNACKPACK_PISTACHIO vs SNACKPACK_VANILLA
- SNACKPACK_PISTACHIO vs SNACKPACK_STRAWBERRY

Step 5: Combine signals into one target function.

Instead of letting EMA alone choose target, use:
- trend_score from fast EMA - slow EMA
- micro_score from imbalance/microprice
- rv_score from family relative z-score

Suggested target logic:
- If trend_score and micro_score agree: full trend target allowed.
- If trend_score and micro_score disagree: half target or passive-only.
- If rv_score is strong and trend_score is weak: trade RV target.
- If rv_score is strong against trend_score: reduce trend exposure unless micro_score also agrees with trend.

This should reduce overfitted directional exposure while adding the robust short-horizon alpha.

4. Backtesting and validation plan

Minimum experiments:

Experiment A: Baseline reproduction
- Confirm local replay reproduces roughly 28.45k on day 4 log conditions.
- Save per-product PnL and drawdown.

Experiment B: Baseline + microstructure execution filter
- Same product whitelist as baseline.
- Only change execution/target gating with micro_score.
- Success criterion: same or higher PnL with lower drawdown, especially fewer bad taker fills.

Experiment C: Microstructure-only SNACKPACK module
- Add all five SNACKPACK names.
- Keep limits small.
- Success criterion: positive standalone PnL on day 4 and no huge inventory mark-to-market dependency.

Experiment D: Family RV module
- First test pair-only rules for the top pairs.
- Then test family basket version.
- Success criterion: improves PnL on validation without relying on a single product's full-day trend.

Experiment E: Combined target
- Combine EMA, microstructure, and RV.
- Compare:
  - final PnL
  - max drawdown
  - per-product contribution
  - number of trades
  - average entry markout over 1, 5, 20 ticks

Validation rule:
- Do not accept a change just because total PnL improves on one day.
- Require at least one of:
  - improves day 4 and does not degrade days 2-3 badly
  - improves risk-adjusted PnL
  - turns a known losing product/module into flat or positive
  - improves fill markouts even if final PnL is similar

5. Do we need to dig deeper for alpha?

Answer: yes, but not before implementing the first two improvements.

We already have enough signal to improve the baseline:
- imbalance_1 and microprice are broad, stable, high-confidence signals
- imbalance_3 has a stable opposite sign and should be included
- family RV gives a second independent alpha source

The deeper alpha work should be targeted, not open-ended:
- Build a proper replay/backtest harness if not already available.
- Measure fill markouts for our own trades, not just public trades.
- Test signal decay by timestamp bucket: early/mid/late day.
- Test product-specific thresholds for SNACKPACK, PEBBLES, MICROCHIP, PANEL.
- Check whether imbalance alpha survives after excluding wide-spread moments.
- Check whether RV signals work better when microstructure confirms the entry.
